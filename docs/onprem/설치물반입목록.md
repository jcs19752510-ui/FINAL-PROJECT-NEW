# 설치물 사전 반입 목록 및 절차 (폐쇄망)

- 목적: 인터넷이 없는 내부망에서 설치와 첫 실행이 멈추지 않도록, **인터넷이 되는 PC에서 부품을 한 번에 받아 번들(폴더)로 만들어 옮긴다.**
- 도구: `scripts/onprem/prepare_offline_bundle.py` (표준 라이브러리만 사용, 파일마다 크기·SHA-256을 `manifest.json`에 기록)
- 원칙: 번들을 만드는 PC와 설치할 PC는 **같은 OS(Windows 64비트)·같은 파이썬 버전**이어야 파이썬 패키지(wheel)가 맞는다.

```mermaid
flowchart LR
  A["인터넷 PC<br/>download"] --> B["번들 폴더<br/>+ manifest.json"]
  B --> C["USB/사내 전송"]
  C --> D["폐쇄망 PC<br/>verify (빠짐·손상 확인)"]
  D --> E["오프라인 설치<br/>pip / npm / docker / 모델 배치"]
  E --> F["인터넷 없이 기동·면접 1회 확인"]
```

## 1. 반입 목록

| 단계 이름 | 반입물 | 누가 쓰나 | 도구가 받는 방법 | 폐쇄망에서 둘 위치 / 설정 |
|---|---|---|---|---|
| `pip` | 파이썬 패키지(`backend/requirements.txt` 전체 + pip/setuptools/wheel) | 백엔드·워커 | `pip download -r ...` (휠 우선, 안 되면 소스 배포본 허용) | `pip install --no-index --find-links <번들>\pip -r backend\requirements.txt` |
| `npm` | 프런트엔드 패키지(`frontend`, `frontend-apply`) | 면접·지원 화면 | `npm ci --cache <번들>\npm-cache` | `npm ci --offline --cache <번들>\npm-cache` (두 폴더 각각). `frontend`는 설치 시 코드 에디터(Monaco)가 자동 복사됨 |
| `docker` | 이미지 4종: `pgvector/pgvector:pg16`, `redis:7-alpine`, `python:3.13-slim`, `node:20-slim` | DB, 큐, 코드 샌드박스 | `docker pull --platform linux/amd64` 후 `docker save` | `docker load -i <번들>\docker\images.tar` |
| `hf` | 음성인식 모델 `Systran/faster-whisper-small`, 임베딩 모델 `paraphrase-multilingual-MiniLM-L12-v2` | STT, RAG | `huggingface_hub.snapshot_download` (HF 캐시 형식, 변환본은 제외) | 폴더 복사 후 환경변수 `HF_HUB_CACHE=<복사한 경로>`, `HF_HUB_OFFLINE=1` |
| `piper` | 음성 합성 음성 `ko_KR-kss-medium`(.onnx, .onnx.json) | TTS | `piper.download_voices`(앱과 동일), 실패 시 HF 직접 받기 | `backend\var\piper_voices\` |
| `deepface` | 표정 분석(감정) 가중치 | 웹캠 표정 분석 | DeepFace를 한 번 실행해 `DEEPFACE_HOME`에 저장 | 폴더 복사 후 환경변수 `DEEPFACE_HOME=<복사한 경로>` |
| `llama` | llama.cpp `b11050` Windows 실행파일 zip 2종(Vulkan, CPU) | 면접 LLM, 화이트보드 | GitHub 릴리즈 직접 받기 | Vulkan zip → `backend\var\llm\bin_vulkan\`, CPU zip → `backend\var\llm\bin_cpu\`에 **압축 해제**(`llama-server.exe`가 그 폴더에 있어야 함) |
| `llm` | LLM `qwen2.5-1.5b-instruct-q4_k_m.gguf`(1,117,320,736 바이트), 비전 `smolvlm-500m-instruct-q8.gguf`, `smolvlm-mmproj-f16.gguf` | 면접 LLM, 화이트보드 | HF에서 받고 SmolVLM은 프로젝트 파일명으로 변경 | `backend\var\llm\models\` |

## 2. 인터넷 PC에서 번들 만들기
```powershell
# 필요 도구: Python, Node.js(npm), Docker Desktop(실행 중), pip install huggingface_hub
# deepface 단계는 deepface·tensorflow가 설치된 파이썬이 필요(예: 백엔드 가상환경에서 실행)
python scripts\onprem\prepare_offline_bundle.py list
python scripts\onprem\prepare_offline_bundle.py download --out D:\bundle --dry-run   # 실행할 일 먼저 확인
python scripts\onprem\prepare_offline_bundle.py download --out D:\bundle
```
- 일부 단계가 실패해도 나머지는 계속 진행되고 종료코드 1이 나온다. 실패한 단계만 `--only 단계이름`으로 다시 실행하면 `manifest.json`이 합쳐져 갱신된다.
- 특정 단계만: `--only pip,npm` / 제외: `--skip docker,deepface`
- **번들을 만든 PC의 파이썬 버전과 설치할 PC의 파이썬 버전을 맞춘다.**

## 3. 폐쇄망 PC에서 확인 → 설치
```powershell
python scripts\onprem\prepare_offline_bundle.py verify --out E:\bundle   # PASS 이어야 진행
```
`verify`는 manifest의 모든 파일에 대해 누락·크기·해시를 확인하고, 만든 PC와 파이썬/OS가 다르면 경고한다. 그다음 1장 표의 "폐쇄망에서 둘 위치 / 설정"대로 설치한다.

**환경변수 주의:** `HF_HUB_CACHE`, `HF_HUB_OFFLINE`, `DEEPFACE_HOME`은 `.env`가 아니라 **운영체제 환경변수(또는 워커·API를 띄우는 시작 스크립트)** 에 설정해야 한다. `.env`는 앱 설정용이라 이 라이브러리들이 읽지 않는다.

## 4. 설치 후 확인 (인터넷을 끊은 상태에서)
1. `python -m app.services.seed_questions` → `python -m app.services.rag_healthcheck`가 PASS (임베딩 모델 로드 확인).
2. 면접 1회: 음성 답변(Whisper), 질문 음성(Piper), 코드 에디터, 화이트보드, 웹캠 표정, 리포트까지 진행.
3. 방화벽 점검 절차(`docs/onprem/방화벽점검절차.md`)로 외부 접속 시도가 없는지 확인.

## 5. 이 도구로 확인하지 못한 것 (정직하게)
| 항목 | 상태 |
|---|---|
| HuggingFace·GitHub·Docker Hub에서 실제로 받아지는지 | 이 서버는 HuggingFace 접속이 차단되고 Docker 데몬이 없어 **실제 다운로드는 못 해봄.** 도구 로직은 가짜 다운로더로, pip·npm은 실제 네트워크로 검증 |
| SmolVLM 저장소/파일명(`ggml-org/SmolVLM-500M-Instruct-GGUF`) | 프로젝트 문서에 출처가 없어 일반 지식 기준. 받기 실패 시 단계가 실패로 표시되며, 현재 사용 중인 PC의 파일(`backend\var\llm\models\`)을 그대로 복사해도 된다 |
| Piper 직접 받기 경로, DeepFace 가중치 위치 | 폴백 경로는 미검증. DeepFace 가중치는 라이브러리가 저장하는 대로 `DEEPFACE_HOME`을 지정하는 방식 |
| 오프라인 설치 후 모델 로드(`HF_HUB_OFFLINE`) | 이 서버에서 모델을 받을 수 없어 실제 로드는 미검증 → 4장 확인으로 검증 |
| 라이선스 | 모델별 사용 조건은 원문으로 확인하지 않음 |
| 이미 가진 파일 재사용 | 현재 개발 PC에 `backend\var\llm`, `backend\var\piper_voices`, HF 캐시가 이미 있다면, 그 폴더를 그대로 복사하는 것이 가장 확실하다 |
