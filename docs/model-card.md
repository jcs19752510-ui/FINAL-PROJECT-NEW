# Model Card — AI 모의면접 플랫폼에서 사용하는 AI 모델

- 작성일: 2026-10-12 (원본 계획서 부록 10 "AI 모델 검증 보고서(Model Card)" 항목)
- 범위: 운영 경로에서 실제로 호출하는 모델과, 코드에는 있으나 서비스에 연결하지 않은 모델을 구분해 적는다.
- **정직한 한계:** 이 문서의 "평가 현황"은 프로젝트에 실제로 남아 있는 근거만 적었다. 정량 평가(WER, 질문 품질 점수, 편향 검증)를 수행한 기록이 없는 항목은 "미실시"로 표시했다. 라이선스는 **일반적으로 알려진 내용**이며 이 프로젝트에서 원문을 확인하지 않았으므로 상용·내부 배포 전 원문 확인이 필요하다.

## 2. 모델별 카드

### 2.1 대화·채점 LLM — Qwen2.5-1.5B-Instruct
- **용도:** 지원자 답변 기반 꼬리질문 생성, 면접 종료 후 STAR·루브릭 채점 JSON 생성.
- **입력/출력:** 시스템 프롬프트(면접관 페르소나, 질문은행 후보)와 사용자 메시지(대화 이력, 최신 답변) → JSON(`speak_text`, `control`, 점수·근거 필드).
- **사용하지 않는 용도:** 합격/불합격의 **자동 최종 판정**(채용담당자가 결정, REQ-031), 법률·의료 판단, 지원자 개인 속성 추론.
- **안전장치:** 구조화 출력 검증 + 1회 재시도, 질문형·플레이스홀더·한국어 비율·시스템 프롬프트 유출 가드, 실패 시 질문은행 문항으로 폴백, 제어 신호 화이트리스트, 프롬프트 인젝션 방어, 요청 빈도 제한.
- **한계:** 1.5B 소형 모델이라 한국어 문장 품질·추론 깊이가 낮다. JSON 필드 누락이 관측돼(unit-37 기준선 3회 중 1회) 재생성 로직을 둠. 시간복잡도 같은 전문 판단은 신뢰하기 어렵다.
- **평가 현황:** 정량 평가 미실시. 결함 이력(DEF-001~011)과 품질 가드 회귀 테스트가 있으나 인간 평가자와의 일치도(Human-AI Agreement)는 측정하지 않음.
- **라이선스(일반 지식, 미확인):** Apache-2.0로 알려짐. 원문 확인 필요.

### 2.2 음성 인식 — faster-whisper small
- **용도:** 지원자 음성 답변 → 텍스트(한국어 고정).
- **한계:** 소형 모델·CPU int8이라 전문 용어·억양에 취약할 수 있다. 실시간 스트리밍이 아닌 턴 단위 배치 처리(실측 RTF 0.22).
- **평가 현황:** **WER 측정 미실시.** 한국어 음성 1건이 정확히 일치한 확인만 있음.
- **데이터 처리:** 오디오는 메모리에서만 처리하고 디스크에 저장하지 않는다.
- **라이선스(일반 지식, 미확인):** Whisper 모델·faster-whisper 모두 MIT로 알려짐.

### 2.3 임베딩 — paraphrase-multilingual-MiniLM-L12-v2
- **용도:** 질문은행 검색(RAG), 코사인 유사도 + MMR.
- **한계:** 질문은행이 자체 제작 15건뿐이라 검색 다양성이 낮다. 유사도 임계치(0.30)는 경험적 값.
- **평가 현황:** 관련/무관 문장 유사도 실측(0.53 vs 0.17) 1회. 검색 품질 벤치마크 미실시.
- **라이선스(일반 지식, 미확인):** Apache-2.0로 알려짐.

### 2.4 음성 합성 — Piper ko_KR-kss-medium
- **용도:** AI 면접관 음성(단일 한국어 음성, 감정 어조 변화 없음).
- **주의:** 음성 데이터(KSS)의 사용 조건은 비상업으로 알려져 있어 **상업적 이용 전 원문 확인이 특히 필요**하다. Piper 엔진 자체는 GPL 계열이라 설계서에 격리 방안이 기록돼 있다.

### 2.5 화이트보드 비전 — SmolVLM-500M-Instruct
- **용도:** 지원자가 그린 다이어그램의 참고용 설명.
- **한계:** 500M 소형 모델이라 정확도가 낮다. 화면에 "AI 참고용" 저신뢰 안내를 고정 노출한다. 평가에 직접 반영하지 않는다.
- **라이선스(일반 지식, 미확인):** Apache-2.0로 알려짐.

### 2.6 표정 감정(DeepFace) · 음성 운율(librosa)
- **표정:** 정지이미지 1장 → 7종 감정 확률. **채용 평가에 반영하지 않는다.** 직장·채용 맥락의 감정 추론은 규제·법적 위험(EU AI Act 금지 대상으로 알려짐, 국내 생체인식 정보 민감정보)이 있어 법무 검토 전 서비스 연결 금지.
- **운율:** pitch/jitter/유성비율/발화 속도 **수치만** 저장한다. "자신감/긴장도" 같은 해석 라벨은 신뢰도 근거가 없어 부여하지 않는다.

## 3. 공통 사항

| 항목 | 내용 |
|---|---|
| 인간 개입 | AI는 보조 도구. 최종 합격/불합격은 채용담당자가 직접 처리(1회 확정) |
| 개인정보 | 생체정보(음성) 별도 동의·철회·즉시 삭제, 저장 시 AES-256-GCM 암호화, 외부 AI 호출 코드 차단(온프리미스 모드) |
| 설명 가능성 | 리포트에 항목별 점수와 근거(대화 인용) 노출 |
| 편향 | 인종·성별·억양 등 집단별 편향 **검증 미실시**(원본 계획서 6.2 항목 미착수). 도입 전 필수 과제 |
| 재현 환경 | llama.cpp b11050, Qwen GGUF 1,117,320,736 바이트(`docs/onprem/설치물반입목록.md`) |

## 4. 알려진 위험과 후속 과제
1. 정량 평가 체계 없음: WER, 질문 품질, Human-AI 일치도 측정 절차 필요.
2. 편향 검증 미실시.
3. 질문은행이 15건이라 질문 다양성 한계.
4. 모델 라이선스(특히 Piper 음성 데이터) 원문 확인.
5. 모델 상향(7B급)과 GPU 서버 도입 시 이 카드를 갱신한다.
