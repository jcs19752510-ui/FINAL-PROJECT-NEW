# unit-33 구현 노트 — GDPR/CCPA (갭 분석 + 데이터 이동권 기술 대응)

- 작성 에이전트: 본 세션, 작성일: 2026-09-22
- 원 계획서 §3.2.2(REQ-028, traceability Out-of-Scope: "국내 시장 대상이라
  한국 개인정보보호법 대응으로 대체")

## 1. 이 유닛이 "GDPR/CCPA 준수"를 코드로 주장하지 않는 이유

GDPR/CCPA 준수는 코드 몇 줄로 달성되는 게 아니라 **법적 판단**(적법 근거
체계 선택, 국외 이전 안전조치, DPO 지정 필요 여부, CCPA "판매" 해당 여부 등)
이 선행되어야 한다. 이 세션은 변호사가 아니다 — 아래는 "기술적으로 무엇이
빠져 있는지"에 대한 엔지니어 관점 갭 분석이지, 법률 자문이 아니다.

## 2. 갭 분석 (현재 PIPA 대응 vs GDPR/CCPA 추가 요구사항)

| 영역 | 현재 상태(한국 PIPA 대응, Feature G) | GDPR/CCPA 추가 요구(기술 관점) | 상태 |
|---|---|---|---|
| 동의 수집 | `POST /consents`(ai_interview_notice/biometric_voice) | GDPR은 "적법 근거"가 동의 외에도 5가지 더 있음(계약 이행 등) — 근거 유형을 DB에 명시적으로 기록해야 함 | ❌ 미구현 |
| 삭제 요청 | `DELETE /users/me/biometric-data`(pending 접수만, unit-14) | GDPR "잊혀질 권리"(Art.17)는 유사하나, 실제 하드 삭제 배치(unit-21, 미착수)가 없으면 이 요구도 미충족 | ⚠️ 부분(원안과 동일 갭) |
| **데이터 이동권**(Art.20) | 없었음 | 기계가 읽을 수 있는 형태로 데이터 제공 | ✅ **이번 유닛에서 구현**(`GET /users/me/data-export`) |
| 국외 이전 | 검토 안 됨 | GDPR은 EU 밖 이전 시 SCC 등 안전조치 필요 — 이 서비스가 실제 EU 거주자를 대상으로 하는지부터 법무 확인 필요 | ❌ 법무 판단 필요 |
| CCPA "판매하지 않음" 고지 | 없음 | CCPA는 개인정보 "판매/공유" 시 옵트아웃 권리 고지 의무 — 이 서비스는 판매하지 않는다면 그 사실 자체를 명시해야 함 | ❌ 미구현(문구만 있으면 됨, 코드 변경 최소) |
| DPO/책임자 연락처 | `frontend/lib/complianceContent.ts`에 국내법 기준 문구만 있음 | GDPR은 일정 조건에서 DPO 지정·연락처 공개 의무 | ❌ 법무 판단 필요 |

## 3. 구현 범위 — 데이터 이동권(Art.20) 기술 대응

- `backend/app/schemas/consent.py`: `DataExportOut`, `InterviewSummaryExport`
  신규 스키마.
- `backend/app/api/v1/consents.py`: `GET /users/me/data-export` 신규 — 계정
  프로필 + 동의이력 + 삭제요청이력 + 면접 세션 요약(대화 원문 제외)을 JSON
  1개로 반환.
- **`TRANSCRIPTS.content_text`(대화 원문)를 의도적으로 제외**했다 — unit-24가
  발견한 인코딩 손상 결함 조사가 끝나기 전까지 그 컬럼을 건드리지 않는다는
  이번 세션 전체의 결정과 동일한 이유.

## 4. 실측 검증 요약(상세는 unit-33-test.md)

실제 서버로 계정 생성→동의→세션생성/시작 후 `GET /users/me/data-export`
호출, 응답에 이메일/이름/동의이력/면접요약이 정확히 포함됨을 확인. 인증
없는 요청은 401로 정상 거부됨을 확인.

## 5. 범위 밖 (인수인계)

- 2절 표의 "❌" 항목들은 이번 유닛이 다루지 않았다 — 특히 "적법 근거 유형
  기록"과 "CCPA 판매하지 않음 고지"는 다음 기술 작업으로 비교적 작은 범위
  (스키마 필드 1개, 문구 1개)이니 우선순위가 있다면 후속 유닛으로 바로 착수
  가능하다.
- 실제 GDPR/CCPA 준수 여부에 대한 최종 판단은 반드시 법무 검토를 거쳐야
  한다 — 이 문서는 그 검토를 대체하지 않는다.
