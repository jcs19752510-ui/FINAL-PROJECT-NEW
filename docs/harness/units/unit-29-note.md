## 미검증이었던 이유 (2026-09-22 원문, 배경 기록용)

`app/services/code_sandbox.py`를 실제로 Docker로 실행해 검증하려는 시도가
**Claude Code 플랫폼 자체의 안전 분류기에 의해 차단됐다**("Create RCE Surface"
사유). 이는 이 세션이 임의로 우회해서는 안 되는 플랫폼 수준의 안전장치다.

결과적으로 당시 다음 중 단 하나도 실측 확인되지 않았었다(2026-09-23 전부 해소,
위 참고):
- 정상 코드(Python/JS)가 실제로 실행되고 출력을 정확히 반환하는지
- 네트워크 차단(`--network none`)이 실제로 적용되는지
- 읽기전용 파일시스템이 실제로 컨테이너 탈출/영구 변경을 막는지
- 메모리/CPU/프로세스 수 제한이 실제로 작동하는지(fork bomb 등 실제 공격
  시나리오로 검증 안 됨)
- 타임아웃 후 강제 종료(`docker kill`)가 실제로 동작하는지
- 좀비 컨테이너가 남지 않는지
