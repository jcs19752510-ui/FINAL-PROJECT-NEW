- 제외 범위 및 사유: 사용자 브라우저에 설치된 특정 확장 프로그램의 정체 규명 — 로컬 개발(localhost:3000, `next dev`)에서만 나타나는 하이드레이션 경고 자체의 1차 유발 요인 후보이나, 실제 배포본에는 해당 여부와 무관하게 이 배지 자체가 존재할 수 없음이 3절/4절로 이미 확정되어 추가 규명 실익이 없음
